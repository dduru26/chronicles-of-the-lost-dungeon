# Chronicles of the Lost Dungeon

A 2D side-view dungeon platformer built in Unity 6. Explore five chambers of the Lost Dungeon, fight three enemy types and a multi-phase boss, solve switch and key puzzles, collect loot, and unlock each chamber in turn.

The project is built around modular, event-driven systems so that new enemies, abilities, interactables and levels can be added without changing existing code.

- Unity 6000.4.7f1, Universal Render Pipeline (2D)
- Input System
- Addressables for runtime content loading
- Unity Test Framework (NUnit)
- JSON save system
- REST API leaderboard

| Action | PC / WebGL | Mobile |
|---|---|---|
| Move | A / D or Arrow keys | Left on-screen stick |
| Jump | Space | Jump button |
| Attack | J or Left click | Attack button |
| Ability 1 / 2 | K / L | Ability buttons |
| Interact | E | Interact button |
| Pause | Esc | Pause button |
